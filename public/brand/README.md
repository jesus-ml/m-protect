Logotipo que usa la app (barra lateral, encabezado móvil y PDF):

- `logo.png`      → versión para fondo claro (fondo transparente)
- `logo-dark.png` → versión para modo oscuro (letras claras)

Para cambiarlo, reemplaza estos archivos. También acepta `logo.svg` / `logo-dark.svg`,
que tienen prioridad si existen. Si no hay ningún archivo, la app muestra el nombre en texto.
Usa el logotipo solo con autorización para usar la marca.
